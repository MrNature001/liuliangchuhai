# 自动客服

分两层：

- **第一层：闲鱼自带自动回复**——设置一次，关键词触发，不用你在线。
- **第二层：实时回复助手**——买家问了没覆盖的问题，粘一句给我，我给回复。

---

## 第一层：闲鱼自动回复（复制进去，5 分钟配置完）

路径：闲鱼 App → 我的 → 设置 → 消息通知 → 自动回复（或「快捷回复」）。
把下面的关键词和回复逐条加上。

### 关键词：价格 / 多少钱 / 报价

```
看您要哪种：

· 单张配图 30 元
· 10 秒短视频 80 元
· 一整套（配图+视频+六套文案）200 元
· 加真人照片口播 +100 元

先告诉我是做什么产品，我看看适不适合，不合适我不接。
```

### 关键词：怎么做 / 流程 / 要什么

```
很简单，三步：

1. 您发我：产品照片 + 几句话介绍（卖给谁、有什么讲究）
2. 我先做一版给您看
3. 满意再付款，两天内交付

照片用手机拍的就行，不用专业设备。
```

### 关键词：能便宜吗 / 优惠 / 少一点

```
价格是实价，不过第一次合作我可以多送一张配图。

或者您先做单张图 30 元试试效果，觉得值再做整套。
```

### 关键词：多久 / 什么时候 / 急

```
常规两天。加急的话当天可以，但要先确认我手上的排期。

您把产品资料发我，我现在就能说具体时间。
```

### 关键词：什么产品 / 能做什么

```
茶叶、食品、特产、手作类做得最多，其他品类也能试。

核心是：能拍出照片、能说清卖点的产品，我就能做。
您是什么产品？
```

### 关键词：AI / 真的假的 / 效果

```
是 AI 生成的，我会按您的产品和目标客群定制场景，不是套模板。

先做一张给您看，不满意不收钱——这样您没风险。
```

## 第二层：实时回复助手

买家问了上面没覆盖的，把他的话粘给我，我给你回。

命令行用法：

```sh
uv run --project apps/api python -I scripts/reply.py "这个能便宜点吗，我买十套"
```

---

## 三条原则

1. **先问产品，再报价**。不知道做什么就给价格，容易被压价。
2. **不接做不了的**。产品拍不出、说不清的，直接说"这个我做得不好"，比硬接回来返工强。
3. **每条回复以问句结尾**。对话留在你这边，成交率高得多。

---

## 必须标注

交付的图和视频，如果客户要拿去投放，**必须带「AI 生成」标识**。
这是 2025 年 9 月施行的《人工智能生成合成内容标识办法》的硬要求，客户不标会被平台处罚，你也有责任提醒。
